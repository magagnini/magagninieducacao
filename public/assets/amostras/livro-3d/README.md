# Pasta de Amostras do Livro 3D (FlipBook)

Coloque aqui as imagens das páginas do livro que você preparou para a demonstração (degustação) de 20 páginas.

### Formato recomendado:
- Nomeie as imagens em ordem sequencial para facilitar a leitura automática:
  - `pagina-01.png` (ou `pagina-01.jpg` / `pagina-01.webp`)
  - `pagina-02.png`
  - `pagina-03.png`
  - ... até `pagina-20.png`
- A página 01 pode ser a capa ou a primeira folha de rosto, seguida das páginas duplas.
- Resolução recomendada: largura entre 800px e 1200px (proporção padrão de folha A4 / livro).
